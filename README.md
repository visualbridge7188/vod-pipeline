# 🎬 VOD Pipeline v3.0 (모두를 위한 VOD 자동 아카이빙 & 노션 교안 생성기)

> **"기술을 이해하지 못해도 괜찮습니다. 유튜브나 웹 강의 주소만 넣으면 알아서 720p로 영상을 저장하고, 핵심 장면만 캡처하여 예쁜 노션 교재로 만들어주는 똑똑한 비서입니다."**

---

## 💡 리처드 파인만식으로 이해하는 이 도구의 원리

우리가 긴 인터넷 강의(2~4시간짜리)를 들을 때 겪는 고통을 떠올려보세요:
1. 영상을 보다가 필기하느라 일시정지 누르고,
2. "아까 그 슬라이드가 몇 분에 나왔더라?" 하며 마우스로 타임라인을 뒤적거리고,
3. 강의가 끝나면 배운 건 많은데 정작 머릿속에 정리가 안 됩니다.

이 프로그램은 여러분 옆에서 실시간으로 일하는 **'수석 서기이자 요리사'**입니다.

* 🍳 **1단계: 최고 신선도의 재료 가져오기 (720p 다운로드)**  
  유튜브든, 멤버십 영상이든, 비메오든 주소만 주면 화질이 깨지지 않는 **선명한 720p 영상**으로 안전하게 내 컴퓨터로 가져옵니다.

* 📸 **2단계: 결정적 순간만 골라 사진 찍기 (스마트 프레임 추출)**  
  강사님이 멍하니 말하고 있을 때는 가만히 있다가, **새로운 PPT 슬라이드를 띄우거나 중요한 화면을 시연하는 순간**에만 카메라 셔터를 찰칵 누릅니다. 강의당 딱 15~25장의 핵심 사진만 모아줍니다.

* 🎙️ **3단계: 1초도 안 놓치고 받아적기 (인공지능 전사)**  
  강사님의 말을 토씨 하나 안 틀리고 정확하게 받아적습니다. 영상에 이미 자막이 있다면 무료로 1초 만에 가져오고, 자막이 없으면 똑똑한 인공지능(Whisper)이 귀를 기울여 완벽한 글자로 바꿉니다.

* 📖 **4단계: 알록달록 예쁜 책으로 엮기 (2패스 노션 교안 생성)**  
  기계처럼 "5분 요약, 10분 요약" 하지 않습니다. 책의 목차를 먼저 짜듯 **'주제 단위'로 챕터를 나누고**, 중요한 내용은 **형광펜**을 칠하고, 공식과 수치는 **예쁜 상자(콜아웃)**에 담고, 오늘 내가 당장 실천해야 할 일은 **체크박스(To-Do)**로 정리해 노션에 꽂아줍니다.

* ☁️ **5단계: 내 구글 드라이브 금고에 영구 보관 (클라우드 일원화)**  
  영상과 사진을 내 구글 드라이브에 차곡차곡 넣어두고, 노션 맨 위에 **"클릭하면 노션 안에서 바로 재생되는 비디오 플레이어"**까지 연결해 줍니다.

## 🚀 3분 만에 시작하는 초간단 설치 및 사용법

### 1. 준비물 설치 (딱 한 번만 실행)
터미널(맥의 Terminal 또는 윈도우의 PowerShell)을 열고 아래 명령어를 복사해서 붙여넣으세요:

```bash
# 1. 필수 도구 설치 (Mac 기준)
brew install ffmpeg yt-dlp

# 2. 파이썬 라이브러리 설치
pip install -r requirements.txt
```

### 2. 영상 다운로드 및 노션 교안 만들기 (단 한 줄!)
```bash
python pipeline.py "https://www.youtube.com/watch?v=내강의주소" --notion-db "내_노션_DB_ID"
```

## 📁 폴더 구성
* `downloader.py`: 유튜브, 비메오, 웹 스트리밍 등 어떤 플랫폼이든 720p로 무손실 다운로드
* `frame_extractor.py`: 챕터 시작 슬라이드 및 화면 시연 구간 집중 캡처 엔진
* `transcriber.py`: 한국어 자막 우선 추출 및 Whisper AI 음성인식 전사
* `notion_syncer.py`: H1-H2-H3 계층 트리, 형광펜, 체크리스트, 콜아웃 완벽 렌더러
* `gdrive_uploader.py`: Google Drive 폴더 생성 및 720p 영상·프레임 일괄 아카이빙
* `PROMPTS.md`: AI 코딩 에이전트(Codex, Claude, Cursor)에게 바로 복붙하는 프롬프트 모음
