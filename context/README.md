# 🗂️ 병원마케팅 대행 프로젝트 맥락 자료 (Context Knowledge Base)

이 폴더는 병원마케팅 대행 5주 8강(총 10강) 과정의 모든 강의 내용, 실전 비즈니스 모델, 노션 자료실 에셋 링크 및 액션 체크리스트를 다른 대화 세션에서도 완벽하게 불러와 활용할 수 있도록 구축된 통합 지식 허브입니다.

---

## 📂 파일 구성 안내

1. **`01_COURSE_ARCHITECTURE.md`**:
   - 5주 8강(총 10강) 전체 커리큘럼 로드맵, 강사진 구성, 3대 수익화 모델(정기결제/MSO/RS), 5대 세일즈 퍼널(랜딩/메타/유튜브/쓰레드/블로그), 대행사 운영 철학.
2. **`02_NOTION_RESOURCES_INDEX.md`**:
   - 노션 35개 실전 에셋(큐카드, 통화 녹음본, 10분 제안서 프롬프트, 실행사 리스트, 계약서 양식, 블로그 템플릿, 키워드 리스트, 의료법 가이드 등)의 영구 링크 및 용도 색인.
3. **`03_LECTURE_CORE_SUMMARY.md`**:
   - 1강~4강의 핵심 주제별 타임라인 요약, 강사의 실전 어록, 수익화 성공 사례 및 환불 방어 비법.
4. **`04_ACTION_CHECKLISTS.md`**:
   - 1강~4강 공식 네이버 카페 인증 과제 및 1주차 실무 실행 체크포인트.
5. **`notion_resources.index.json`**:
   - 노션 자료실 리소스의 정형화된 JSON 데이터 (프로그래밍 쿼리용).
