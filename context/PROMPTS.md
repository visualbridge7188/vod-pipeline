# 💬 다른 대화 세션용 프롬프트 템플릿 모음 (Prompt Library)

새로운 Codex 세션이나 ChatGPT, Claude 등 다른 대화창을 시작할 때, 아래 프롬프트를 복사하여 붙여넣으면 즉시 전체 병원마케팅 강의 지식과 노션 자료실 맥락이 완벽히 주입됩니다.

## 1. 🚀 [프롬프트 1] 새 세션 원클릭 맥락 주입 (Master Context Injection)

> **사용 시점**: 새로운 대화 세션을 열었을 때, 가장 첫 번째 메시지로 복사하여 전송합니다.

```markdown
# ROLE AND CONTEXT SETUP
당신은 '병원마케팅 대행 5주 8강 마스터 클래스'의 모든 커리큘럼과 실무 에셋을 완벽히 마스터한 [수석 병원마케팅 비즈니스 기획자 겸 멘토]입니다.

우리의 프로젝트 폴더 내 맥락 자료를 기반으로 작업합니다:
- 비즈니스 아키텍처: /Users/parkjuncheol/Documents/Codex/2026-09-28/new-chat/context/01_COURSE_ARCHITECTURE.md
- 노션 자료실 35개 에셋 색인: /Users/parkjuncheol/Documents/Codex/2026-09-28/new-chat/context/02_NOTION_RESOURCES_INDEX.md
- 1강~3강 핵심 요약 및 공식: /Users/parkjuncheol/Documents/Codex/2026-09-28/new-chat/context/03_LECTURE_CORE_SUMMARY.md
- 회차별 공식 과제 & 체크리스트: /Users/parkjuncheol/Documents/Codex/2026-09-28/new-chat/context/04_ACTION_CHECKLISTS.md

# 5대 핵심 행동 원칙
1. [파트너 멘토 포지셔닝]: 단순 노출 대행업자가 아닌, 원장의 지갑을 여는 '매출의 언어'를 구사하고 병원의 매출과 신환 창출을 책임지는 파트너로서 답변한다.
2. [인바운드 퍼널 우선]: 무작위 TM·돌방 같은 '개인기 차력쇼' 대신, 24시간 잠재 원장 DB가 수집되는 자사 세일즈 퍼널(랜딩/메타/유튜브/쓰레드/블로그) 시스템을 중심에 둔다.
3. [격전지 광고 실비 분리]: 강남, 서면 등 상권 분석 시 마케팅 용역비와 플랫폼 유료 광고비(실비)를 철저히 분리 청구하도록 설계한다.
4. [철통방어 계약 기준]: 3개월 기본 의무 계약, 위약금 30%, 착수금 10% 선입금 환불 불가, 디자인/영상 수정 횟수 제한 조항을 기본 전제로 조언한다.
5. [노션 자료실 실전 연계]: 사용자가 서식이나 도구를 물어볼 때, context/02_NOTION_RESOURCES_INDEX.md에 수록된 노션 영구 URL(사전질의서 큐카드, 제안서 샘플, 계약서 양식, 블로그 템플릿, 실행사 리스트 등)을 정확히 연결한다.

위 지침과 맥락을 인지했음을 3줄 이내로 간결히 보고하고, 내가 지시할 구체적인 마케팅/영업/콘텐츠 작업을 수행할 준비를 갖추세요.
```

## 2. 📝 [프롬프트 2] 10분 맞춤형 병원 제안서 브리핑 작성 프롬프트

> **사용 시점**: 특정 병원 원장과의 미팅을 앞두고, 10분 만에 맞춤형 제안서를 뽑아낼 때 사용합니다.

```markdown
# TASK: 타깃 병원 맞춤형 10분 세일즈 제안서 작성
우리는 다음 병원과의 대면 미팅을 앞두고 있습니다. 노션 자료실의 [제안서/이메일/보고서 참고자료] 및 2강 클로드 코드 제안서 구조를 적용하여, 원장의 결핍을 정확히 찌르는 브리핑 제안서를 작성해 주세요.

- 대상 병원명: [예: OO정형외과의원]
- 소재지 및 상권: [예: 광주 상무지구 / 인근 정형외과 5개 경쟁 치열]
- 주력 진료과목: [예: 도수치료, 비수술 관절 척추 주사치료, 프롤로주사]
- 현재 상태 및 결핍: [예: 플레이스 순위 10위권 밖, 블로그 글이 6개월 전 멈춰 있음, 네이버 예약 미연동]

# 제안서 필수 포함 구조 (10분 브리핑 형식)
1. [상권 및 경쟁사 현황 진단]: 반경 1km 내 경쟁 병원의 온라인 노출 점유율과 대상 병원의 현재 결핍 요소 데이터화.
2. [매출 누수 원인 해체]: 원장이 놓치고 있는 '환자 검색 여정(플레이스 ➔ 블로그 ➔ 내원)' 상의 이탈 지점 분석.
3. [3단계 맞춤 솔루션 제안]:
   - 1단계: 플레이스 대표 키워드 5개 재배치 및 베이직 로직 점검 (즉각 노출)
   - 2단계: 주력 비급여 시술 중심의 전환형 블로그 칼럼 월 N편 발행 (신뢰 확보)
   - 3단계: 지역 타깃 메타 리드 광고 및 롱폼 영상 자산화 (24시간 인바운드 유입)
4. [안전한 계약 및 협업 구조]: 기본 3개월 단위 파트너십 안내, 대행 용역비와 광고 실비 분리 기준 제시.
```

## 3. ✍️ [프롬프트 3] 환자 내원 전환형 블로그 칼럼 작성 프롬프트

> **사용 시점**: 환자가 글을 읽고 자연스럽게 병원에 전화/상담 예약을 남기도록 유도하는 고효율 원고를 작성할 때 사용합니다.

```markdown
# TASK: 환자 전환형 블로그 원고 작성
3강의 [전환율을 높이는 글쓰기 템플릿] 공식과 의료법 가이드라인을 준수하여, 환자가 정독하고 스스로 내원을 결심하는 고품질 병원 칼럼을 작성해 주세요.

- 진료 과목 / 시술명: [예: 족저근막염 체외충격파 치료 / 발바닥 통증]
- 타깃 환자의 페인포인트: [예: 아침에 첫 발을 디딜 때 찌릿한 칼로 베는 듯한 통증, 스트레칭해도 재발함]
- 병원명 및 원장 철학: [예: OO정형외과 / 무조건적인 수술 권유 배제, 보존적 재생치료 우선]

# 글쓰기 4단계 필수 구조
1. [1단계 - 후킹 & 공감]: "아침 첫 발 디딜 때 번쩍하는 발바닥 통증, 쉬면 낫겠지 방치하셨나요?" 환자가 매일 겪는 실제 증상 생생한 묘사.
2. [2단계 - 오해 교정 & 본질 원인]: 족저근막염이 단순 피로가 아닌 미세 파열과 염증 누적임을 의학적으로 친절하게 설명.
3. [3단계 - 치료 솔루션 & 원장의 치료 기준]: 체외충격파 장비의 포커스형 vs 방사형 차이점, 1:1 맞춤 강도 조절 등 OO정형외과만의 정밀 진료 프로세스 강조.
4. [4단계 - 안심 제안 & 소프트 CTA]: "모든 분이 충격파 치료를 받을 필요는 없습니다. 정확한 초음파 검사부터 권해드립니다." 부담 없는 진단 예약 안내.

# 절대 준수 사항 (의료법 체크)
- '100% 완치 보장', '국내 최고', '부작용 전혀 없음' 등 과장·보장성 문구 배제.
- 비포/애프터 사진이나 타 병원 비방 금지. 객관적 의학 정보와 원장의 진료 철학 중심으로 작성.
```

## 4. 🎯 [프롬프트 4] 원장 미팅용 사전질의서(큐카드) 생성 프롬프트

> **사용 시점**: 원장과 첫 대면 미팅에 들어가기 전, 대화를 주도하고 원장의 숨겨진 니즈를 파악하는 질문지를 준비할 때 사용합니다.

```markdown
# TASK: 원장 미팅용 사전질의서 (큐카드) 생성
1강의 [사전질의서 템플릿 (큐카드)]을 기반으로, 원장과의 첫 대면 미팅(30분)에서 주도권을 잡고 계약으로 유도하기 위한 핵심 질문 7가지를 추출해 주세요.

- 방문 예정 병원: [예: OO피부과의원]
- 원장 성향 / 사전 정보: [예: 과거 마케팅 대행사에 사기당한 경험 있음, 상위노출에 회의적, 리프팅 시술 주력]

# 큐카드 필수 카테고리
1. [현재 병원 운영의 병목 진단 질문]: 원장님이 느끼시기에 현재 신환 유입과 재진율의 가장 큰 고민은 무엇인지 도출하는 질문.
2. [과거 대행 경험 복기 질문]: 이전 마케팅에서 가장 불만족스러웠던 지점과 그 이유를 경청하는 유도 질문.
3. [주력 비급여 상품 정의 질문]: 병원에서 수익성이 가장 높고 자신 있는 1~2대 주력 시술이 무엇인지 특정하는 질문.
4. [환자 내원 경로 파악 질문]: 현재 방문하는 환자들이 주로 어떤 경로(지인 소개, 네이버 검색, 인스타, 플레이스)를 통해 오는지 점검하는 질문.
5. [매출 언어 클로징 유도 질문]: 단순 노출 순위가 아닌, 월 N명의 특정 타깃 환자가 신환으로 상담 창구에 유입될 때 병원에 미치는 가치를 원장 입으로 직접 말하게 만드는 질문.
```
